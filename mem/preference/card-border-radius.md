---
name: Card Border Radius
description: Keep dashboard card corner radius modest and professional; avoid oversized rounding unless explicitly requested.
type: preference
---
Dashboard cards, stat cards, and content panels should use a modest border radius (e.g., MUI `borderRadius: 2` / 16px) for a clean, professional look. Avoid heavy rounding on card containers unless the user explicitly asks for a more playful or bubbly aesthetic. Inner elements such as avatars, input bars, and nested papers should also stay small and consistent.
