---
name: Clean Classnames
description: Use semantic, human-readable class names for all HTML elements to ensure maintainability and clarity.
type: preference
---
All HTML elements should use semantic, human-readable class names (e.g., `dashboard-container`, `sidebar-nav`, `stat-card`) alongside utility classes. This improves code readability and makes it easier to understand the structure of the UI at a glance. Avoid relying solely on utility classes without descriptive names.
